# Celestrial assets

2026-10-15 확정 조합. Outfit, Manrope, DM Mono는 공식 Google Fonts에서 받아 OFL 라이선스와 함께 포함했다. Cormorant Garamond는 짧은 천체 지도 레이블에 사용한다.

`sky-stars.svg`와 `sky-atlas.svg`는 코드로 작성한 장식용 도해이며 실제 관측 데이터가 아니다. 사용자 제공 Celestial 문서의 표현 방향을 A/B 선택에 맞춰 적용했다. `dashboard.css`와 `editorial.css`는 확정된 직각 유리 디자인을 적용한다.
